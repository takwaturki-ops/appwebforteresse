1 — Contexte & objectifs

Projet pédagogique SecOps : construire pas à pas une app de gestion d'infrastructure hautement sécurisée, sans Docker (app + PostgreSQL natifs sous WSL2 Ubuntu, n8n sur Azure).

  • Apprendre chaque mécanisme, pas juste l'empiler
  • Tester par attaques réelles simulées
  • Tracer chaque événement en audit

3 grands chantiers

  • A. App web + 2FA + RBAC + OWASP
  • B. API REST JWT + journal d'audit
  • C. Surveillance automatique n8n

6 — Audit + API

Audit : 1 ligne JSON / événement, append-only. Lu via /admin/audit (web superadmin) et /api/audit.

{"action":"RATE_LIMIT_BLOCAGE","level":"warning","username":"turki"}
{"action":"ACCESS_DENIED","username":"stagetest","chemin":"/admin/users"}
{"action":"PRIVILEGE_ESCALATION_BLOCKED","level":"critical","username":"admintest"}
{"action":"LOGIN_SUCCESS","username":"turki"}
{"action":"CSRF_BLOCKED","chemin":"/login"}

API : POST /api/login → JWT 15 min → GET /api/users, POST /api/users/:id/role, GET /api/audit. Même RBAC + rate-limit que le web.
